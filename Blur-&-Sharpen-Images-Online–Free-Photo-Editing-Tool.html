How browser-native mathematical kernels transform image frequencies in real-time

Separable Gaussian

2D Isotropic Gaussian

Rather than performing costly 2D matrix convolutions, our engine splits the Gaussian function into an initial horizontal 1D pass followed by a vertical 1D pass.

G(x) = (1 / √(2πσ²)) · e^[ -x² / (2σ²) ]
Unsharp Masking

Edge Difference Amplification

Originated in traditional darkrooms. We create an unsharp low-frequency copy of the image, subtract it from the original to extract pure spatial edge gradients, and add it back scaled.

I_sharp = I_orig + α · (I_orig - I_blur)
High-Pass Filter

Micro-Contrast Boost

Extracts the highest frequency fine details while centering midtones at 50% neutral gray. Overlay blend boosts tactile texture without washing out luminance.

HP(x, y) = clamp(I_orig - I_blur + 128)
